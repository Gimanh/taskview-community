# ERP Budget Monitoring Integration

Bridge the gap between project delivery teams and corporate financial systems (SAP, Oracle Cloud, NetSuite, Microsoft Dynamics 365).

## Triple-Entry Financial Monitoring

TaskView tracks financial performance using a three-tier model:

1. **Allocated Budget**: Approved funding envelope for the project or work package.
2. **Committed Amount**: Signed vendor contracts, purchase orders (POs), and encumbrances.
3. **Actual Expenditures**: Approved invoices, general ledger (GL) journal entries, and payments.

$$\text{Remaining Budget} = \text{Allocated} - (\text{Committed} + \text{Actuals})$$

$$\text{Variance (\%)} = \left( \frac{\text{Actuals} + \text{Committed}}{\text{Allocated}} \right) \times 100$$

## Work Breakdown Structure (WBS) & Cost Centers

- Assign project line items to ERP Cost Centers (e.g., CC-IT-4200) and WBS codes (e.g., WBS-2026-CLOUD-01).
- Drill down from overall project budget into itemized GL transactions.

## ERP Webhooks & Synchronization

- **Inbound Webhook**: Receive automated invoice and PO event notifications from ERP systems at `/module/erp/webhook`.
- **Manual / Scheduled Sync**: Trigger full budget reconciliation via `/module/erp/sync`.
