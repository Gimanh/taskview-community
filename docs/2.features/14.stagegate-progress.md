# Stagegate Progress Calculation

Rather than relying on subjective status estimates, TaskView calculates stagegate and project progress mathematically using task completion and deliverable verification.

## Formula & Logic

### Gate Progress
Each gate's progress is calculated from the ratio of completed exit criteria tasks to total assigned tasks:

$$\text{Gate Progress} (\%) = \left( \frac{\text{Completed Tasks}}{\text{Total Assigned Tasks}} \right) \times 100$$

### Overall Project Progress
The overall project progress is computed as the weighted average across all active stagegates:

$$\text{Project Progress} (\%) = \sum_{i=1}^{n} \left( \text{Gate Progress}_i \times \text{Weight}_i \right)$$

Where weights reflect phase significance (e.g., Execution carries a higher weighting than Initiation).

## Real-Time Recalculation API

The backend automatically updates gate and project progress whenever:
- A task within a stagegate is completed or reopened.
- An exit criteria item is updated.
- A manual recalculation is triggered via `/module/stagegates/:gateId/recalculate`.
