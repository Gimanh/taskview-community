TaskView has a few single-key shortcuts for the most frequent actions. Press **?** anywhere in the app, or open **Settings → Keyboard shortcuts** at the bottom of the settings page, to see the list.

## Shortcuts

### Everywhere

| Key | Action |
|---|---|
| `C` | New task. Opens the add-task dialog with the project and list you are looking at already selected; on the home screen it picks the project you used last, or the Inbox. The task appears right away in the open list, kanban board or graph. |
| `Cmd+K` / `Ctrl+K` | Search tasks. Type `#123` to find a task by its number. |
| `?` | Show the list of keyboard shortcuts. |
| `Esc` | Close a dialog or the open task. |

### Open task

| Key | Action |
|---|---|
| `X` | Mark the open task complete, or reopen it. Needs the permission to change the task status. |

## When shortcuts do not fire

- While you type in a text field, the task title or the note editor — the key is typed as usual.
- While a dropdown, a confirmation or the search is open over the page.
- With `Cmd`, `Ctrl` or `Alt` held, so `Cmd+C` still copies.
- On a phone-sized screen and in the mobile apps.

Letter shortcuts follow the physical key, so they work the same with any keyboard layout, including Cyrillic ones.

## Turning shortcuts off

If single-key shortcuts get in your way, for example they clash with a browser extension, turn them off in **Settings → UI customization → Others → Keyboard shortcuts**. The setting is personal and follows you across devices. `Cmd+K` and `Esc` keep working.

Choosing your own keys is not available yet.
